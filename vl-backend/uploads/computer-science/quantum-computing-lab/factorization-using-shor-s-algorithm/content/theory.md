<h4>Conventional databases</h4>

<p>
A conventional database is a centralized system used to store, manage, and retrieve data.
It is controlled by a single organization or authority and allows authorized users to insert,
update, and delete records easily.
</p>

<div style="text-align-center;">
</div>

<h4>Blockchain databases</h4>


<p>
A blockchain database is a distributed digital ledger where data is stored across multiple nodes in a network.
Each block contains a set of transactions and is cryptographically linked to the previous block,
ensuring data integrity and transparency.
</p>

<div style="text-align-center;">
</div>
<h4>Properties</h4>

<p>
The following properties highlight the key differences between conventional databases and blockchain databases.
</p>

<table border="1" cellpadding="8" cellspacing="0" width="100%">
  <tr>
    <th>Property</th>
    <th>Conventional Database</th>
    <th>Blockchain Database</th>
  </tr>

  <tr>
    <td><strong>Immutability</strong></td>
    <td>
      Data in conventional databases is mutable. Authorized users can update, modify,
      or delete existing records directly. Older data can be overwritten and may not be preserved.
    </td>
    <td>
      Data in blockchain databases is immutable. Once a transaction is recorded and added to the chain,
      it cannot be altered or deleted. Any update is stored as a new transaction, preserving full history.
    </td>
  </tr>

  <tr>
    <td><strong>Decentralization</strong></td>
    <td>
      Conventional databases are centralized. A single organization or server has complete control
      over data storage, access, and management.
    </td>
    <td>
      Blockchain databases are decentralized. Data is distributed across multiple nodes,
      and no single entity has full control over the database.
    </td>
  </tr>

  <tr>
    <td><strong>Performance</strong></td>
    <td>
      Conventional databases offer high performance with fast read and write operations.
      They are optimized for large volumes of transactions and real-time applications.
    </td>
    <td>
      Blockchain databases generally have lower performance due to consensus mechanisms,
      cryptographic validation, and network-wide agreement before adding transactions.
    </td>
  </tr>

 

</table>
